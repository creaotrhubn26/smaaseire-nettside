Familiens data

SmåSeire fungerer lokalt på iPhonen. Dere velger selv om dere vil dele familien via iCloud.

Gjelder SmåSeire 1.1 og 1.2. Sist oppdatert 16. oktober 2026.

Hvem står bak?

SmåSeire leveres av Creatorhub AS. Kontakt om appen og personvern: daniel@creatorhubn.com.

Dette lagres på telefonen

Appen lagrer profilnavn eller kallenavn, valgte figurer, oppgaver, premier, fullføringer, godkjenninger, poeng og innstillinger. Fra versjon 1.2 lagres også valgt aldersgruppe, støttevalg, morgenrutiner og fremgang i rutinene. Ingen diagnose er nødvendig eller etterspurt. Opplysningene brukes til å vise og holde orden på familiens vaner og fremgang. Bruk gjerne kallenavn. Appen trenger ikke fødselsdato, adresse, posisjon eller kontaktlisten din.

Foreldrekoden lagres som en saltet kontrollverdi i iPhonens nøkkelring, ikke som lesbar kode. Den synkroniseres ikke av SmåSeire. Appen oppretter ingen egen brukerkonto.

Valgfri iCloud-deling

Når en voksen aktivt kobler familien til iCloud, lagres familieprofiler, oppgaver, premier og fremgang i Apples CloudKit, i en privat database. I versjon 1.2 inngår også morgenrutiner med valgt aldersgruppe, støttevalg og fremgang i delingen. Inviterte voksne med redigeringstilgang kan lese og endre den delte familien. Foreldrekode og lokale påminnelsesinnstillinger deles ikke.

Creatorhub AS har ikke tilgang til innholdet i familiens private CloudKit-database. Apple håndterer Apple-kontoen, skytjenesten og invitasjonene etter Apples personvernregler. iCloud krever en Apple-konto på enheten. Del bare med voksne du stoler på.

Ingen reklame eller sporing

Appen inneholder ingen annonse-, sporings- eller tredjepartsanalyseverktøy. Vi mottar ikke familiens profiler, oppgaver eller poeng på en egen server. Apple kan behandle drifts- og diagnosedata for sine tjenester i tråd med dine Apple-innstillinger. Tilbakemeldinger du frivillig sender gjennom TestFlight, kan bli tilgjengelige for utvikleren gjennom Apple.

Sesongfunksjoner fra versjon 1.2

I appversjoner med julemodus får hele appen et juletema i desember når sesongen er aktivert av SmåSeire-admin. Appen henter en offentlig av/på-innstilling fra GitHub Pages. Forespørselen inneholder ikke profilnavn, ønskelister, gaveplaner eller en egen brukeridentifikator. GitHub kan behandle tekniske forespørselsdata, som IP-adresse, for å levere tjenesten. Ønskelister, besøksplaner og gaveoversikter lagres på telefonen og inngår ikke i appens iCloud-deling. Gaveoversikten krever foreldrekoden. Når julemodus avsluttes sentralt, skjules innholdet og beholdes lokalt til neste sesong.

Påminnelser

Varsler krever ditt samtykke i iOS og planlegges lokalt på telefonen. De viser ikke profilnavn eller poeng på låseskjermen. Slå dem av i SmåSeire eller i iPhonens varselinnstillinger.

Lagring, deling og sletting

Lokale familiedata beholdes til de endres eller appens data fjernes. Sletting av appen fjerner dens lokale data, men sletter ikke automatisk iCloud-data eller kopier på andre enheter. Nøkkelringopplysninger kan beholdes av iOS etter avinstallasjon.

«Koble fra denne telefonen» stopper videre synkronisering på den telefonen og beholder familien lokalt. Det avslutter ikke delingen for andre. Familiens eier kan administrere deltakere og stoppe deling gjennom appens Apple-delingsvindu. iCloud-data administreres gjennom Apple-kontoens iCloud-lagring. Eventuelle sikkerhetskopier som eksporteres til Filer, og lokale kopier hos andre voksne, må håndteres separat.

Ved synkroniseringskonflikter kan appen lagre lokale sikkerhetskopier for å bevare familiens data. Slike kopier ligger på telefonen, eller på stedet du selv velger ved eksport.

Henvendelser til oss

Hvis du sender e-post, mottar vi e-postadressen og innholdet du sender, slik at vi kan svare. Ikke send foreldrekoder eller unødvendige personopplysninger om barn. Kontakt oss om innsyn, retting eller sletting av opplysninger du har sendt oss. Vi kan ikke hente ut eller slette familiens private iCloud-innhold på dine vegne.

For familien

En voksen bør sette opp appen, velge hvilke navn og oppgaver som lagres, og administrere eventuell deling. SmåSeire har ingen offentlig profil, offentlig innholdsstrøm eller chat.

Denne nettsiden

Sidene bruker ingen analyseverktøy eller egne informasjonskapsler. Nettsiden leveres av GitHub Pages. GitHub kan behandle tekniske forespørselsdata, som IP-adresse, for å levere og beskytte tjenesten. Se GitHubs personvernerklæring.
